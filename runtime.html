Workflow support

This release has been verified with GitHub Actions.

Jobs run on the host

Jobs run with the files and permissions of the account running Ferrun. Run only workflows you trust. Jobs are not sandboxed or isolated from other jobs on the same computer.

Ferrun does not support job containers, service containers, or Docker-based actions. Using Docker for PostgreSQL does not put workflow jobs in containers.

Install the tools your workflow uses

Install Git, the requested shell, and any build tools on the computer running the jobs. Ferrun does not install these tools for you.

Windows uses PowerShell by default. Linux and macOS use Bash, with sh as a fallback. Workflows that select another shell need that shell installed.

JavaScript actions that use Node 20 or Node 24 need the matching version installed. Set EXECUTOR_NODE20 or EXECUTOR_NODE24 when it is not available on PATH.

Runner labels select existing computers

A workflow’s runs-on label selects a registered runner. Changing its label does not create a virtual machine or install an operating system.
