JSON field reference

releases.json lists available downloads, checksums, and test results.

If no release is available, the target list is empty and release-specific fields are omitted.

/format
The format version of this JSON file. This page describes version 1.
/distribution_repository
The private repository from which the publisher obtains release files.
/tag
The release tag used in the download URLs.
/source_commit
The Git commit used to build the release.
/runner_version
The GitHub runner version selected when the release was built.
/live_qualification_passed
Whether the release passed the GitHub Actions compatibility checks.
/release_url
The release page with its notes and downloads.
/metadata_url
The original release.json file, copied without changes from the build repository.
/targets/*/target
The operating system and processor identifier, such as aarch64-unknown-linux-gnu for Linux ARM64.
/targets/*/platform
The readable name of the same operating system and processor.
/targets/*/archive
The download’s filename, without directory names.
/targets/*/sha256
The SHA-256 checksum of the complete downloaded archive, including its manifest.
/targets/*/bytes
The download size in bytes.
/targets/*/download_url
The public download URL on this website. GitHub sign-in is not required.
/targets/*/checksum_url
The separate checksum file for this download.
/targets/*/tests_url
The test report for this download. It records the source commit and archive checksum.
