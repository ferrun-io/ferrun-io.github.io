Release catalog

Read releases.json for the displayed release.

/format
Catalog schema version. This reference describes version 1.
/distribution_repository
Public repository serving the bundles; distinct from their source repository.
/tag
Exact version tag used in all asset URLs.
/source_commit
Immutable implementation identity recorded in the build inventory and manifests.
/runner_version
Recorded GitHub runner compatibility pin; not proof of service compatibility.
/live_qualification_passed
False for this build/test preview. Do not treat it as an approved customer trial release.
/release_url
Public release notes and asset listing.
/metadata_url
Unmodified original build inventory, including its source repository attribution.
/targets/*/target
Native Rust target. Select only the computer’s actual OS and architecture.
/targets/*/platform
Readable platform label for the same target.
/targets/*/archive
Exact flat asset name; not a source-code archive.
/targets/*/sha256
SHA-256 of the complete compressed archive, including its manifest.
/targets/*/bytes
Compressed download size in bytes.
/targets/*/download_url
Public bundle URL requiring no source repository credentials.
/targets/*/checksum_url
Matching sidecar checksum file.
/targets/*/tests_url
Native test report bound to the same source and archive digest.
